# Design references and project design system

`figma.design.md`, `anthropic.design.md`, and `clay.design.md` are third-party design references and are not the visual specification for this product. The CMS uses its own product-specific system documented in [`CMS-DESIGN.md`](CMS-DESIGN.md).

The interactive component showcase is [`front-end/design-system.html`](front-end/design-system.html). It is static demo UI and is not connected to Apps Script, Sheets, or Docs. Do not treat demo content as production data.
